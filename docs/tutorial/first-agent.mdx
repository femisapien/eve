Build a data analytics assistant with sample data. You'll add SQL queries, sandboxed charts, a metric glossary, team playbooks, and approval for queries above a simulated cost threshold. You don't need a warehouse or Vercel Connect account. To start from a different use case, browse the [eve template gallery](https://eve.dev/templates).

## Prerequisites

- Node 24 or newer and npm.
- A model credential. Complete [Getting Started](../getting-started) first if you have not connected one; `/login` can sign you in or accept an API key.

## Scaffold the agent

```bash
npx eve@latest init analytics-assistant
cd analytics-assistant
```

`init` creates the directory, installs dependencies, initializes Git, and offers to start the server. If you accepted, stop the server before editing the files below.

## Give it an analyst persona

`agent/instructions.md` is the always-on system prompt. Replace the starter text with a standing identity for a data analyst:

```md
You are a senior data analyst. You answer questions about the team's data.

- Prefer exact numbers to hand-waving. If you can compute it, compute it.
- State the assumptions behind any number you report (date range, filters, grain).
- Use the tools available to you rather than guessing. If you cannot answer from
  the data, say so plainly.
```

## Run the agent

```bash
npm run dev
```

The scaffold's `dev` script starts the local server and terminal UI. Ask a question it can answer without your data:

```text
What's a good way to measure week-over-week retention?
```

The agent cannot query your data yet. Next, see [how eve runs each turn](./how-it-runs).
